# CSV 导出交付前的检查

本教程是本次开发自写的中文验收材料，不是外部作者文章；用于验证内容转 Skill 能否保留中文步骤并生成可运行的检查能力。

## 第一步：按列名读取

使用 Python 标准库 csv.DictReader 读取 CSV，不用逗号 split，因为名字字段可能包含逗号。按 UTF-8（可带 BOM）打开，newline 设为空字符串。

接收一个文件路径、标识列名和必需列名列表。默认标识列为 id，默认必需列为 id、name；用户可以传入中文列名。必需列缺失时记录缺失列名，不补造列。

## 第二步：检查标识为空

对标识列去首尾空白。值为空时记录该数据记录的序号，第一条数据记为记录 1。这是逻辑数据记录序号，不等同于文件物理行号，因为 CSV 字段可以包含换行。

## 第三步：检查重复标识

对非空标识按字符串精确比较，区分大小写。重复时记录标识、首次记录序号和当前记录序号。空标识不再重复计数。若文件没有标识列，只报告缺失列，停止标识值检查。

## 第四步：给出检查结果

输出一个 JSON，包含 row_count、missing_columns、empty_ids、duplicate_ids。检查失败返回退出码 1，全部通过返回 0；读文件或 CSV 解析异常返回 2 并说明错误，不修改原 CSV。

列完整且标识非空、无重复，只代表本教程定义的结构检查通过，不代表姓名、业务内容或数据来源真实。不要擅自删除重复记录。
